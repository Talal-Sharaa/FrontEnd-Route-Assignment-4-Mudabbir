# Mudabbir — مدبّر

A responsive, right-to-left personal finance dashboard built with semantic HTML and plain CSS.

## Run locally

Open `index.html` in a browser. There are no build tools or packages to install.

## Pages and sections

The dashboard includes balance cards, recent activity, transactions, monthly bills, budget progress, a weekly income and expenses chart, payment methods, and account summaries.

The navigation links jump to dashboard sections. Financial values are sample data; this is a static front-end layout without backend functionality.

## Layout

- Desktop: fixed-width sidebar and a two-column dashboard grid.
- Tablet: a compact sidebar with sections rearranged to fit the screen.
- Mobile: horizontal navigation and vertically stacked sections.

The supplied assignment images and icons are stored in `assets/`.
